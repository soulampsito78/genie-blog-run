# Today 문장 검증과 이미지 증거 판정

2026-10-28 Today 장애에서 서버 검증을 통과한 본문에 비문이 남았다. 기존 문구 치환은 명사구를 삽입해 동사 활용을 깨뜨릴 수 있었으며, 당시 실행의 치환 전 출력은 보존되지 않아 직접 인과는 확정하지 않는다.

## 문장 검증

- 생성 단계의 치환은 문장의 목적어와 동사 활용을 유지하며, 입력에 없던 금리·환율·수급 변수를 일괄 삽입하지 않는다.
- 이미 잘못된 `수급 흐름하는` 계열 접합이 들어와도 최종 Today validator와 고객 표면 검사가 모두 오류로 진단한다. 제목·별도 채널 제목·인사·요약·시장 맥락·TOP3·기회·리스크·마감 문장을 확인한다.
- 고객 표면 검사는 내용을 고치거나 지우지 않는다. 원문과 수치를 보존한 채 검토 필요를 표시한다. 이 진단은 한국어 문법 전체를 인증하지 않는다.
- frozen 부모 기사 재발행에는 서버 작성시각·발행일·부모를 결속하고 시점 중립 문체를 사용한다. 날짜·달력 결속을 확인하지 못하면 모델 호출 전에 거부한다.
- `첫 30분 수급을 확인합니다` 등 현재 지시형을 진단하되, `전일 첫 30분 수급`이나 `오늘 장전 발표된 실적` 같은 과거 사실 자체를 시점 오류로 바꾸지 않는다. 기사 속 사건시각과 작성·발송시각을 구분한다.
- 정규식과 생성 시점 검증은 발송 직전의 전체 독립 검수를 대신하지 않는다. 정상 자연 생성이 오래 지연된 경우도 실제 발송 문맥을 다시 확인한다.

## 이미지 검수

서버 문장 validator와 독립 이미지 검수는 서로 다른 책임이다. 내용 PASS를 이미지 권리 PASS로 쓰거나 이미지 미확인을 문장 validator의 거부라고 보고하지 않는다.

기준 이미지의 경로·SHA·승인된 외형 규칙은 기준 자산 식별 증거다. 실제 출력과의 바이트/lineage 결속, 동일 캐릭터의 시각 검수, 기존 생성·소유 또는 사용 허락 원본의 허용 범위를 따로 확인한다. 특정 이름의 registry 파일이나 건별 새 승인서를 새 필수 양식으로 추가하지 않는다. 이미 유효한 원본은 같은 자산·범위에 결속해 재사용하며 매번 Owner에게 재승인을 묻지 않는다.

참조 파일이 존재한다는 사실만으로 사용권을 추정하지 않으며, 별도 대장이 없다는 사실만으로 권리 침해를 확정하지 않는다. 필요한 근거가 아직 확인되지 않은 항목은 정확한 UNKNOWN으로 남긴다. 외형의 닮음·워터마크·파일 소유 계정·Git 커밋만으로 미확인 근거를 채우지 않는다.

이번 변경은 이미지 권리 가드나 서명·수신권리·publication/claim 가드를 해제하지 않는다. 보류된 과거 후보를 덮어쓰거나 REOPEN하지 않고, 이미 사용한 복구 3회를 환급하거나 네 번째 재발행 권한을 만들지 않는다. 운영 반영과 실제 복구 발행·SMTP·고객 수신은 각각의 실제 결과로 기록한다.

## 지속 회귀

`scripts/run_product_regression_gate.py`는 새 문장·과거 사실 보존·진단 불변성 unittest를 실행한다. Cloud Build의 기존 오프라인 pytest 단계는 재발행 문맥과 기존 body-only 교정 경계 시험도 수집한다. 합성 시험 PASS를 실제 후보 전체 검수나 고객 발송 성공으로 보고하지 않는다.
